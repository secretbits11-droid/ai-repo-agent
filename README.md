# Telegram Test Bot

A lightweight Python Telegram Bot built with `python-telegram-bot` (v20+) for testing deployment, command handlers, and real-time live log streaming.

## Features

- `/start` command response confirming bot status.
- `/ping` command response for quick health checks.
- Timestamped stdout logging for testing real-time log streaming.

## Prerequisites

- Python 3.8 or higher
- A Telegram Bot Token (obtained from [@BotFather](https://t.me/BotFather))
